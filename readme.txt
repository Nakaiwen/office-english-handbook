社畜英語訓練手冊 / Office English Survival Handbook
====================================================

版本：VOL. IV
類型：純前端英文學習工具，對標 CEFR B2 / Linguaskill Business
主檔案：office-english-handbook-artifact.html
語言：繁體中文介面 + 英文職場句型

----------------------------------------------------
1. 專案簡介
----------------------------------------------------

《社畜英語訓練手冊 / Office English Survival Handbook》是一款以職場英文為主題的互動式學習工具。
它用復古紙本訓練教材的視覺風格，將常見辦公室英文句型、商務黑話、情境應答、跟讀練習，與一份完整的半年學習計畫，整合在單一 HTML 頁面中。

工具的核心目標：

- 幫助使用者快速理解英文職場語境中的「表面意思」與「真正含意」。
- 提供結構化的 26 週學習計畫，目標讓使用者半年達到 CEFR B2 / Linguaskill Business 達標程度。
- 涵蓋 7 大職場主題分類，並依 CEFR 等級分級內容難度。
- 不只是單純背句型，而是學習在尷尬、催促、拒絕、澄清、推進決策等情境中，使用更自然且得體的英文回應。

----------------------------------------------------
2. 主要功能
----------------------------------------------------

2.1 每日金句（共 40 句）

顯示一組職場英文句型，包含：

- 英文句子
- 中文翻譯
- 主題分類標籤
- CEFR 等級徽章
- 對應檢定技能標籤
- 使用情境
- 言外之意
- 實戰對話
- 單句播放發音
- 整段對話播放
- 主題篩選器（依主題只看相關句型）
- 下一句切換（在篩選範圍內輪轉）
- 收藏功能

範例句型包含：

- Let's circle back on this.
- I'd like to request leave from May 20 to May 24.
- Could you walk me through this real quick?
- Just to make sure I understood correctly...
- I'd like to build on what Sarah just said.
- I've been feeling a bit stretched — could we talk about prioritization?

2.2 黑話翻譯機（共 45 則）

整理常見辦公室英文黑話，將「他們嘴上說的話」翻譯成「實際想表達的意思」。

每筆資料包含：

- 英文黑話
- 中文表面意思
- 真正含意
- 主題分類

使用者可透過：

- 搜尋欄輸入關鍵字（即時篩選）
- 主題篩選器（依主題集中複習）

兩者可同時生效。

2.3 情境快問（共 20 題）

以中文職場情境作為題目，讓使用者從多個英文回應中選出最合適的一句。

功能包含：

- 主題分類標籤
- CEFR 等級徽章
- 題目情境說明
- 多選題回答
- 答對 / 答錯即時顯示
- 正解講評
- 跟讀練習
- 主題篩選器
- 下一題（篩選範圍內輪轉）
- 從頭再來
- 答對、答錯、準確率統計
- 重置分數
- 答題紀錄持久保存（用於進度追蹤）

2.4 我的收藏

使用者可在「每日金句」中收藏想複習的句子。
收藏後可在「我的收藏」頁籤集中查看。

每張收藏卡會顯示：

- 英文句型
- 中文意思
- 言外之意
- 發音播放按鈕
- 移除收藏按鈕

2.5 學習計畫（VOL. IV 新增）

對標 Linguaskill Business / CEFR B2，提供視覺化的半年衝刺路線圖。

功能包含：

- 26 週四階段路線圖
- 起跑日設定（按下後開始倒數）
- 自動計算目前所在週次與階段
- 四張階段卡片（顯示週次區間、CEFR 目標、主題重心、階段目標、技能聚焦）
- 各主題進度條（顯示已學會的句子數 + 答對的題目數 / 總數）
- 重置進度（會清除學習紀錄，但保留收藏）

四階段架構：

- Phase 1 / Foundation 紮根（週 1-6）
  CEFR：A2 鞏固 → 入門 B1
  主題：日常任務、請假出缺
  目標：把基本句型套到自動反射

- Phase 2 / Active 主動參與（週 7-13）
  CEFR：B1 穩定運作
  主題：會議、跨部門
  目標：開會敢開口、跨部門能 reach out

- Phase 3 / Influence 影響力（週 14-20）
  CEFR：B1+ → 跨入 B2
  主題：主管應對、Email
  目標：能跟主管推進議題、能寫結構嚴謹的 email

- Phase 4 / Polish 收尾（週 21-26）
  CEFR：B2 達標
  主題：整合所有主題
  目標：模擬 Linguaskill Business 題型實戰

2.6 語音播放與跟讀

本工具使用瀏覽器內建的 Web Speech API / SpeechSynthesis 功能進行英文發音播放。

支援：

- 每日金句單句播放
- 對話逐句播放
- 對話播放時高亮目前句子
- 對話 A/B 角色音調差異化
- 黑話項目播放
- 測驗正解跟讀
- 收藏句型播放
- 發音速度切換：慢速、正常、流暢

若瀏覽器不支援語音合成，頁面會顯示提示，建議使用 Chrome、Safari 或 Edge。

3. 主題分類系統（VOL. IV 新增）
----------------------------------------------------

所有學習內容皆標註以下其中一個主題：

- general       萬用通則 — 跨情境的經典職場句型與骨灰級黑話
- time-off      請假出缺 — 病假、特休、OOO、WFH、遲到、外出
- daily         日常任務 — Standup、卡關求助、走流程、交辦工作
- meeting       會議     — 遲到、斷訊、插話、附議、push back、hard stop
- cross-team    跨部門   — Reach out、flag 問題、escalate、ownership
- managing-up   主管應對 — 1:1、加薪、犯錯回報、被批評、要 sign-off
- email         Email    — 開場、追信、催延期、回 stakeholder

每個主題在介面上有獨立顏色編碼，便於快速辨識。

每筆內容額外標註：

- cefr：CEFR 等級（A2 / B1 / B2）
- skill：主要對應技能（speaking / writing / listening / reading）

4. CEFR 對應與檢定目標
----------------------------------------------------

對標檢定：Linguaskill Business（劍橋領思職場英語檢測）
  原名 BULATS，2019 年由劍橋大學語言測評考試院升級為 Linguaskill Business
  分數對應 CEFR A1 ~ C1+
  測驗項目：聽讀（AI 適性）、口說、寫作

目標等級：CEFR B2

CEFR 等級在本工具的內容意義：

- A2：基礎句型、例行性回應、formulaic 表達
- B1：結構化對話、提問釐清、簡單反對、跨部門 reach out
- B2：委婉表達、結構性論述、推進議題、危機應對

半年達標的真實期待：
從 A2-B1 起點，到第 26 週實際大概落在「強 B1 跨入 B2」。
要正式報考 Linguaskill Business 達 B2，可能需要再加 1-2 個月的真題訓練。

5. 操作方式
----------------------------------------------------

1. 直接用瀏覽器開啟 office-english-handbook-artifact.html。
2. 進入頁面後，預設顯示「每日金句」。
3. 點擊上方頁籤切換功能：

   - 01 每日金句
   - 02 黑話翻譯機
   - 03 情境快問
   - 04 我的收藏
   - 05 學習計畫

4. 在「每日金句」中：

   - 點擊上方主題晶片可篩選只看特定主題的句型。
   - 點擊「下一句 NEXT」在篩選範圍內切換。
   - 點擊喇叭圖示播放英文發音。
   - 點擊「播整段對話」播放完整情境對話。
   - 點擊「★ 收藏」儲存句型。

5. 在「黑話翻譯機」中：

   - 上方主題晶片可篩選主題。
   - 輸入關鍵字即可同時搜尋（兩種篩選可疊加）。

6. 在「情境快問」中：

   - 上方主題晶片可篩選主題。
   - 讀取中文情境。
   - 選出最得體的英文回應。
   - 查看講評與正解。
   - 使用跟讀功能練習正確句型。
   - 答對的題目會自動記錄到進度追蹤。

7. 在「我的收藏」中：

   - 查看已收藏句型。
   - 播放收藏句型發音。
   - 移除不需要的收藏。

8. 在「學習計畫」中：

   - 第一次使用按下「設定起跑日」啟動倒數。
   - 系統自動顯示你目前在第幾週、第幾階段。
   - 各階段卡片中，目前階段以紅框 + 淡紅底高亮，已完成階段以淡化顯示。
   - 主題進度條即時反映你已學會的內容比例。
   - 「重置進度」會清除學習紀錄，但不影響收藏。

6. 技術架構
----------------------------------------------------

本工具為單檔純前端專案，主要由以下部分組成：

- HTML：頁面結構與五大功能面板（含主題篩選器、學習計畫面板）
- CSS：復古紙本文書風格、響應式版面、主題色彩編碼、CEFR 徽章樣式
- JavaScript：資料渲染、頁籤切換、測驗邏輯、收藏、語音播放、主題篩選、計畫進度計算、狀態儲存

主要資料常數：

- THEMES：主題定義（label / short / color / emoji）
- PLAN：26 週學習計畫（4 phases，各含 start/end 週次、CEFR 目標、主題、目標、技能聚焦）
- PHRASES：每日金句資料（40 筆，含 theme/cefr/skill 標籤）
- DECODER：黑話翻譯機資料（45 筆，含 theme 標籤）
- DRILLS：情境快問題庫（20 筆，含 theme/cefr 標籤）

主要狀態：

- currentPhraseIdx：目前每日金句索引
- currentDrillIdx：目前測驗題目索引
- favorites：收藏句型集合（Set）
- score：測驗分數（correct / wrong）
- speechRate：語音播放速度
- phraseThemeFilter / decoderThemeFilter / drillThemeFilter：各分頁的主題篩選狀態
- phraseFilteredIdx / drillFilteredIdx：篩選後的索引清單（用於導覽）
- learnedPhrases：已標記學會的句子集合
- attemptedDrills：已嘗試的題目索引
- correctDrills：答對的題目索引
- planStartDate：學習計畫起跑日（ISO 日期字串）

----------------------------------------------------
7. 狀態儲存
----------------------------------------------------

工具會透過 window.storage 儲存使用者狀態。

目前儲存項目包含：

- favorites：已收藏句型
- score：情境快問答對 / 答錯紀錄
- speechRate：使用者選擇的發音速度
- learnedPhrases：已掌握的句子集合（VOL. IV 新增）
- attemptedDrills：已嘗試過的題目（VOL. IV 新增）
- correctDrills：答對的題目（VOL. IV 新增）
- planStartDate：學習計畫起跑日（VOL. IV 新增）

如果執行環境沒有 window.storage，工具仍可正常使用，只是不會保存狀態。

11. 如何新增內容
----------------------------------------------------

11.1 新增每日金句

在 JavaScript 的 PHRASES 陣列中新增一筆物件：

{
  en: "英文句型",
  zh: "中文翻譯",
  theme: "meeting",       // 必填：主題分類
  cefr: "B1",             // 必填：CEFR 等級（A2 / B1 / B2）
  skill: "speaking",      // 必填：技能（speaking / writing / listening / reading）
  context: "使用情境",
  subtext: "言外之意",
  dialogue: [
    ["A", "對話第一句"],
    ["B", "對話第二句"]
  ]
}

11.2 新增黑話翻譯

在 DECODER 陣列中新增：

{
  said: "英文黑話",
  saidZh: "中文表面意思",
  meant: "真正含意",
  theme: "general"        // 必填：主題分類
}

11.3 新增情境快問題目

在 DRILLS 陣列中新增：

{
  theme: "meeting",       // 必填：主題分類
  cefr: "B1",             // 必填：CEFR 等級
  situation: "中文情境描述",
  options: [
    { text: "選項 A", correct: false, why: "講評" },
    { text: "選項 B", correct: true, why: "講評" },
    { text: "選項 C", correct: false, why: "講評" },
    { text: "選項 D", correct: false, why: "講評" }
  ]
}

每題建議只有一個 correct: true 的選項。

11.4 主題分類值（theme 必須為下列之一）

- general
- time-off
- daily
- meeting
- cross-team
- managing-up
- email

如需新增主題，需同時更新 THEMES 常數，提供 label、short、color 三個欄位。

----------------------------------------------------
12. 注意事項
----------------------------------------------------

- 本工具為靜態網頁，不需要後端伺服器。
- 若直接用本機瀏覽器開啟即可使用大部分功能。
- 語音功能取決於瀏覽器與系統語音支援。
- 收藏與分數若無 storage 支援，重新整理後可能不會保留。
- 半年達 CEFR B2 為理想目標，實際達成依練習頻率而定（建議每週 5-8 小時穩定練習）。
- 學習計畫起跑日設定後即固定，週次自動由系統根據今天日期計算。
- 「重置進度」會清除學習紀錄與起跑日，但不會影響收藏。
- 所有學習內容偏向幽默化與情境化，適合用於職場英文語感訓練，不建議當成正式商務英文唯一標準。

----------------------------------------------------
15. 專案一句話
----------------------------------------------------

這是一份讓你在英文職場裡「聽得懂場面話、說得出安全話、必要時還能優雅脫身」，並能在半年內把口說程度從「會議閉嘴」推到「能 push back」的互動式生存手冊。
